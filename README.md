# OpenCity: 언리얼 엔진 5 오픈월드 범죄 샌드박스 프로토타입

GTA 스타일 게임의 **핵심 시스템 뼈대**를 UE5 C++로 구현한 프로젝트입니다.
바이너리 에셋(.uasset/.umap)이 하나도 없습니다. 도시, 입력, HUD는 전부 코드로 만들어지고
스토리는 JSON 파일로 관리합니다.

> 현실적인 범위: GTA5는 수천 명이 수년간 만든 게임입니다. 이 저장소는 그 수준의 콘텐츠가 아니라
> 자유도(오픈월드, 차량, 경찰, 미션)와 최적화 구조를 갖춘 **플레이 가능한 기반**입니다.
> 그래픽 품질은 지금 기본 도형(그레이박스) 위에서 Lumen GI, 가상 그림자 맵, 대기 산란이 담당합니다.
> 실제 아트(캐릭터, 차량, 건물)를 넣으면 그 위에 그대로 올라갑니다.

## 실행 방법

1. Unreal Engine **5.8**과 Visual Studio 2022(“C++를 사용한 게임 개발” 워크로드)를 설치합니다. 런처의 **새 프로젝트**가 아니라, 이 저장소의 `OpenCity.uproject`를 엽니다.
2. `OpenCity.uproject`를 우클릭한 뒤 **Generate Visual Studio project files**를 선택합니다.
3. `OpenCity.uproject`를 더블클릭하면 C++ 모듈 빌드를 묻습니다. **Yes**를 누릅니다.
4. 에디터에서 **Play**를 누릅니다. 빈 맵이어도 게임 모드가 도시, 하늘, 플레이어를 자동으로 생성합니다.

한글이 네모(□)로 보이면 Noto Sans KR 같은 한글 폰트를 임포트하고
`Config/DefaultGame.ini`의 `FontPath`에 그 폰트 에셋 경로를 지정하세요.

| 시스템 | 파일 | 내용 |
|---|---|---|
| 절차적 도시 | `OCCityGenerator` | 14×14 블록 격자, 도심일수록 높아지는 고층 빌딩, 공원과 나무, 가로등, 차선, 주차 차량 |
| 플레이어 | `OCCharacter` | 3인칭 이동·달리기·점프, 조준 줌, 히트스캔 사격, 체력 자동 회복 |
| 차량 | `OCVehicle` | 레이캐스트 서스펜션 아케이드 물리, 드리프트(핸드브레이크), 충돌 피해, 화재 후 폭발, 야간 헤드라이트, 뒤집힘 복구 |
| 교통 AI | `OCVehicle`(AI 모드) | 우측 차선 주행, 교차로 회전, 장애물 감지 후 정지 |
| 보행자 | `OCPedestrian` | 인도 순환, 횡단보도 건너기, 총성·폭발에 공황 상태로 도주, 차에 치이면 래그돌 |
| 수배 시스템 | `OCWantedSubsystem` | 목격자가 있어야 범죄로 집계, 0~5성, 별 수에 비례한 경찰 투입, 시야에서 벗어나면 수배 해제 |
| 경찰 AI | `OCPoliceOfficer` | 마지막 목격 위치 추적, 도로망 경로 탐색, 이동 속도에 따른 명중률 |
| 스토리·미션 | `OCStorySubsystem`, `Content/Story/Story.json` | 미션 5개, 대사 자막, 목표 7종, 보상, 자동 저장 |
| 환경 | `OCWorldEnvironment` | 실시간 낮과 밤(해와 달), 하늘 대기, 볼류메트릭 안개, 실시간 스카이라이트 |

## 최적화 설계

- 도시의 모든 정적 지오메트리를 HISM(Hierarchical Instanced Static Mesh) 레이어 10여 개로 묶습니다.
  수천 개 건물을 레이어당 드로우콜 하나로 그리고, 작은 소품은 인스턴스별 컬링 거리를 둡니다.
- 인구 스트리밍: 보행자와 교통 차량을 플레이어 주변 링에서만 생성하고 멀어지면 제거합니다. 동시에 존재하는 수에 상한이 있습니다.
- NPC 틱 LOD: 플레이어와의 거리에 따라 액터와 이동 컴포넌트의 틱 간격을 늘리고 그림자를 끕니다.
- 차량 휴면: 멀리 있는 주차 차량은 물리 시뮬레이션과 틱을 끄고, 가까워지거나 충돌·피격되면 깨어납니다.
- 태양 회전은 0.5초 간격으로만 갱신해 그림자 캐시 무효화를 줄입니다.
- 렌더링: Lumen, VSM, TSR 업스케일(`r.ScreenPercentage=75`)을 사용합니다.

## 스토리 수정하기

`Content/Story/Story.json`만 고치면 됩니다. C++ 재컴파일은 필요 없습니다.
좌표 `[x, y]`는 도로 교차로 번호입니다(0~14).

```json
{ "type": "eliminate", "text": "적을 처치하라", "at": [10, 9], "count": 3 }
```

목표 타입: `goto`, `enter_vehicle`, `drive_to`, `eliminate`, `lose_wanted`, `survive`(`seconds`), `get_wanted`(`stars`)

## 다음 단계 (GTA급으로 가기 위한 로드맵)

1. **아트 교체**: 기본 도형 메시를 마네킹·MetaHuman 캐릭터, Chaos Vehicle 차량, 메가스캔/Nanite 건물로 교체합니다.
2. **월드 규모**: World Partition과 PCG 프레임워크로 도시를 수 km 단위로 확장하고 지형, 바다, 고속도로를 추가합니다.
3. **군중과 교통**: Mass Entity / Mass Crowd로 수천 명 단위의 보행자와 차량을 운용합니다.
4. **연출**: 시퀀서 컷신, 음성, 라디오, 사운드(MetaSounds), 애니메이션(Motion Matching)을 추가합니다.
5. **게임플레이**: 무기 종류, 상점, 은신처, 경찰차·헬기 추격, 저장 슬롯, 사이드 미션을 추가합니다.
